# CA-Markov Urban Growth Model with CODESZone Regulatory Constraints
### Ouargla, Algeria | Peer Review Package

---

## Overview

This repository contains the Python scripts used in the study:

> **"Operational Urban Forecasting: Coupling CA-Markov with Regulatory
> Instruments for Sustainable Planning of Saharan Cities — Ouargla Case Study, Algeria"**

The scripts reproduce all quantitative results reported in the manuscript,
including the CA-Markov simulation, model validation, ROC/AUC analysis,
and publication figures.

## Data Requirements

The following datasets are required and must be placed in the paths
specified in `BASE_DIR` at the top of each script.

| Dataset | Format | Source |
|---------|--------|--------|
| Urban land-cover maps (1990, 2000, 2010, 2025) | GeoTIFF (binary 0/1) | Sentinel-2 / Landsat, RF classification |
| CODESZone regulatory zones | Shapefile (field: `code_zone`) | Direction de l'Urbanisme, Wilaya d'Ouargla |
| Future urban perimeter | Shapefile | Direction de l'Urbanisme, Wilaya d'Ouargla |
| Road network | Shapefile | OpenStreetMap / municipal data |

Satellite imagery is freely available from:
- Landsat: https://earthexplorer.usgs.gov
- Sentinel-2: https://scihub.copernicus.eu

Regulatory data are available from the Directorate of Urban Planning
and Construction, Wilaya of Ouargla, Algeria, subject to a
data-sharing agreement.

## Installation

```bash
# 1. Clone or download this repository
# 2. Create the conda environment
conda env create -f environment.yml
conda activate ouargla_urban_growth

# 3. Edit BASE_DIR in each script to match your local data path
```

---

## Execution Order

Scripts must be run in sequence:

```bash
# Step 1 - CA-Markov simulation (2025->2045)
python ca_markov_urban_growth.py

# Step 2 - ROC/AUC validation (requires Step 1 outputs)
python roc_auc_analysis.py

# Step 3 - Publication figures (requires Steps 1 and 2)
python generate_figures.py
```

## Key Parameters

| Parameter | Value | Script |
|-----------|-------|--------|
| Spatial resolution | 30 m | all scripts |
| Projection | UTM Zone 31N (EPSG:32631) | all scripts |
| Calibration epochs | 1990-2000, 2000-2010 | ca_markov_urban_growth.py |
| Validation period | 2010-2025 (15 years) | roc_auc_analysis.py |
| Projection horizon | 2025-2045 (20 years) | ca_markov_urban_growth.py |
| CA neighbourhood | Moore 3x3 | ca_markov_urban_growth.py |
| CODESZone weights | code 0=1.0, code 1=0.0, code 2=0.8 | ca_markov_urban_growth.py |
| Expansion threshold | 0.40 | ca_markov_urban_growth.py |

## Reproducibility Notes

1. **Random seed**: set to 42 in roc_auc_analysis.py for reproducible
   stratified sampling.
2. **CODESZone field**: the regulatory shapefile must contain a field
   named exactly `code_zone` with integer values 0, 1, or 2.
3. **Execution time**: the CA-Markov simulation uses fully vectorised
   NumPy operations. Expected runtime on a standard workstation
   (Intel Core i7, 32 GB RAM): approximately 2-5 minutes per script.
